# Харлампий Шишкин — предвыборная программа

Статический сайт для GitHub Pages. Без сборки и внешних зависимостей.

Содержание редактируется в `index.html`, оформление — в `styles.css`. Фотографии и плакаты — в `assets/`.

Размещение: Settings → Pages → Deploy from a branch → main → / (root).

Планируемый адрес: https://harlampij444.github.io/grekov-shishkin/ . Наличие этой строки само по себе не подтверждает публикацию.

Авторские материалы кандидата предоставлены им для его предвыборной кампании. Логотип РХУ использован как принадлежность к училищу; сайт представляет программу кандидата.
